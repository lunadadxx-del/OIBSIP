Each task folder contains the full Android Studio project source, a `README.md`
describing the project, and follows the required `OIBSIP/[TrackName]-[Task]-[ProjectName]/`
naming format.

## Building

Open any task folder in Android Studio and run it on an emulator or device,
or from the command line inside the task folder:

```
./gradlew assembleDebug
```

The debug APK is produced at `app/build/outputs/apk/debug/app-debug.apk`.
